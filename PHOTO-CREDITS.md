# LOA & Behold — Photo Credits & Licensing Ledger

Every photo on loaandbehold.com is logged here before it ships. House rules (Douglas's line):

- **No photos from broker, listing, or dealer sites — ever.**
- Only two sources: (1) builder-published press/media imagery where the builder's terms allow it, or
  (2) openly licensed photos (Wikimedia Commons CC-BY / CC-BY-SA / CC0 / public domain) with the
  credit line carried on the page.
- No fake or stand-in photos. No AI illustrations.

## Checked and NOT used

- **Builder press/media kits (all builders):** no builder press photo ships in batch 1. No builder
  media-kit terms were verified as permitting this use during this batch, so the batch is
  Commons-only. Revisit per builder in a later batch, with the terms logged here first.
- **Broker/listing/dealer sites (YachtWorld, Boat Trader, dealer pages):** never used, per house rule.
- **Sunreef 80 Power (Commons file "Sunreef 80 Power ship in 2021.01.jpg"):** rejected on visual
  check — the boat in the frame carries a sailing rig (mast and boom); the file is mislabeled.
- **Boston Whaler 280 Outrage ("HCG 004.jpg", CC BY-SA 3.0 gr):** genuine model, but the boat is a
  Hellenic Coast Guard patrol fit-out. Withheld — a service-liveried boat is not the face of the
  recreational model. Revisit only with Douglas's OK.
- **Botnia Targa 37 (Swiss police photos, CC BY-SA 4.0):** genuine model in police livery. Withheld
  for the same reason as above.
- **Jeanneau Merry Fisher 695 (Interboot 2020 photo):** the photographed boat is the first-generation
  695; the database carries the 695 Series 2. Skipped — wrong generation.
- **Princess 62 / Princess 72 photos:** database carries the F62 and Y72, different boats. Skipped.
- **Pershing 56 category photo:** its own Commons description identifies it as a Pershing 50; the
  database carries the 50.1. Skipped — identification not clean.
- **Fairline Squadron 58 photo:** Commons description says "probably a 58." Skipped — uncertain ID.
- **Prestige 460 photo:** boat photographed shrink-wrapped in storage. Skipped — not a usable photo.
- **Sea Ray SLX 260 (Interboot 2023 stand photo):** clearly badged SLX 260, a model the database
  does not carry. Skipped.
- US center-console builders (Contender, Freeman, Everglades, Regulator, etc.): no openly licensed,
  cleanly identified photos of database models found on Commons in this batch. The owner-photo
  prompt on every photo-less model page is the fill path for these.
